# Звіт до роботи

## Тема: Загальне тестування та юніт-тести

### Мета роботи

Ознайомитися з основами тестування програм на Python, навчитися використовувати `assert`, `raise ValueError`, бібліотеку `unittest`, а також інструменти `subTest` і `mock`.


### Виконання роботи

**1. Перевірка введеного числа**

- Створено програму для перевірки введеного числа.
- Використано `assert` та `raise ValueError` для перевірки правильності даних.
- Перевірено правильне та неправильне введення.

**2. Тестування функцій**

- Створено функцію підрахунку кількості голосних літер у рядку.
- Написано юніт-тести за допомогою `unittest`.
- Перевірено звичайний, порожній рядок, рядок із цифрами та українськими літерами.

**3. Робота з класом Figure**

- Створено та перевірено об'єкти класу `Figure`.
- Перевірено методи `get_figure_type` та `get_figure_length`.
- Виправлено помилку в реалізації.
- Додано метод `get_angles` та тести для різних геометричних фігур.

**4. Розширені можливості unittest**

- Використано `subTest` для перевірки різних типів фігур.
- Створено функцію з `input()` та протестовано її за допомогою `unittest.mock.patch`.

**5. Результати тестування**

Тут будуть додані скриншоти виконання програми та результати запуску тестів.

### Висновок

Під час виконання лабораторної роботи було вивчено основи тестування програм на Python. Навчився використовувати `assert`, `raise ValueError` та бібліотеку `unittest` для перевірки правильності роботи програм.

Було створено власні функції та класи, написано тести для звичайних і граничних випадків, а також використано `subTest` і `mock`.

Мету роботи досягнуто. Основні завдання виконано. Під час роботи закріплено навички написання та перевірки Python-коду.
